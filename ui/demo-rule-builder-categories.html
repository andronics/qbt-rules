qbt-rulesrule builder — categories concept
Drag a node from a category section onto the canvas. It arrives pre-tagged with that section's domain category (color stripe + corner icon) and, for leaves/actions, a structural sub-type (corner glyph). New nodes start unconnected — wire them up conceptually, they won't appear in the YAML until attached to the tree.
